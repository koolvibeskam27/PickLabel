PickLabel – Android Bluetooth Label Printing App
PickLabel is a fast, reliable Android app built for seamless Bluetooth label printing. Designed for field teams and warehouse operations, it connects instantly to supported Zebra printers and sends clean, formatted ZPL labels with minimal steps. The app focuses on speed, accuracy, and a smooth workflow for on‑the‑go printing.

Features
🔵 Instant Bluetooth SPP connection to Zebra printers

🖨️ Fast ZPL label generation

📄 Preview labels before printing

🔁 Automatic retry & status handling

⚙️ Lightweight, responsive UI

📦 Optimized for warehouse, logistics, and field operations

Tech Stack
Kotlin

Android Studio

Bluetooth SPP / RFCOMM

Zebra ZPL
